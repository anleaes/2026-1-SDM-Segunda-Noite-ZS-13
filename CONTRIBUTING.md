# Como contribuir

## Ambiente

- Python 3.10+
- `pip install -r requirements.txt`
- Copie `.env.example` para `.env` e ajuste credenciais
- Para Oracle, siga [ORACLE.md](ORACLE.md)

## Commits

Use mensagens curtas no imperativo:

- `feat:` nova funcionalidade
- `fix:` correção de bug
- `docs:` documentação
- `chore:` tarefas de manutenção (gitignore, deps)

Mantenha commits **pequenos e focados** (um assunto por commit).

## Pull requests

1. Branch de feature atualizada com `develop`
2. Descreva o que mudou e como testar
3. Aguarde revisão antes do merge
