Arquitetura do Backend

O projeto usa dois acessos aos mesmos models:

1. Templates Django (esta área)

Browser → URL (/portal/...)
       → View (portal/views.py)
       → Model (apps/*/models.py)
       → Template HTML
       → resposta HTML

2. API REST (React Native)

App → HTTP JSON (/api/...)
       → urls.py + Router
       → ViewSet (apps/*/views.py)
       → Serializer (apps/*/serializers.py)
       → Model → JSON

Mapa URL → View → Serializer → Model
